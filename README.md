# BudgetApp

Aplikacja webowa do zarządzania budżetem osobistym oraz rozliczeniami grupowymi.

## Technologie

### Backend
- Java 25
- Spring Boot
- Spring Security
- GraphQL
- JWT
- MySQL

### Frontend
- React
- TypeScript
- Vite

### Inne
- Docker
- GitHub Actions
- SonarCloud

## Funkcjonalności

- Rejestracja użytkowników
- Logowanie JWT
- Zarządzanie transakcjami
- Zarządzanie grupami
- Rozliczanie długów
- Komunikacja GraphQL
